Konektivitas & Driver Industri
  • Driver Simulator Terintegrasi (Fase 1 MVP): Mendukung pengujian end-to-end tanpa memerlukan hardware PLC fisik dengan nilai sinus suhu, RPM, dan register R/W realistis.
  • Tombol Test Connection Interaktif: Mengecek rute soket TCP/IP ke PLC secara instan dengan pelaporan waktu latensi (milidetik) dan indikator status live.
  • Wizard Import & Export CSV Tag: Tambahkan puluhan register mesin dalam sekali klik tanpa perlu menginput manual satu per satu.
  • Transformasi Nilai & Formula: Faktor scale, offset, dan ekspresi aman safe_eval (misal: value * 0.1 - 5) untuk kalibrasi sensor presisi.
Keamanan OT & Otomasi ERP
  • Kontrol Penulisan PLC Berlapis: Setiap tag wajib ditandai is_writable, dibatasi min/max safety range, dan dilengkapi wizard konfirmasi eksplisit operator.
  • Alarm Otomatis Menjadi Work Request Maintenance: Terintegrasi dengan maintenance.request lengkap dengan mekanisme debounce anti-duplikasi tiket.
  • Pemisahan Hak Akses 4 Tingkat: SCADA Viewer (Operator), SCADA User (Supervisor/Teknisi), SCADA Engineer (Otomasi), dan SCADA Administrator (IT).
  • Audit Log Append-Only (IEC 62443): Merekam riwayat perintah tulis (siapa, kapan, nilai, asal perintah, dan respon PLC) yang tidak dapat diedit atau dihapus.
