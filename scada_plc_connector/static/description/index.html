Industrial Connectivity & Drivers
  • Built-in Simulator Driver (Phase 1 MVP): Supports end-to-end testing without any physical PLC hardware, using realistic sine-wave temperature, RPM, and R/W register values.
  • Interactive Test Connection Button: Instantly checks the TCP/IP socket route to the PLC, reporting latency in milliseconds with a live status indicator.
  • CSV Tag Import & Export Wizard: Add dozens of machine registers in a single click, with no need to enter them manually one by one.
  • Value Transformation & Formulas: Scale factor, offset, and safe safe_eval expressions (e.g. value * 0.1 - 5) for precision sensor calibration.
OT Security & ERP Automation
  • Layered PLC Write Control: Every tag must be flagged is_writable, bounded by a min/max safety range, and backed by an explicit operator confirmation wizard.
  • Automatic Alarms Become Maintenance Work Requests: Fully integrated with maintenance.request, including a debounce mechanism that prevents duplicate tickets.
  • 4-Tier Access Control Separation: SCADA Viewer (Operator), SCADA User (Supervisor/Technician), SCADA Engineer (Automation), and SCADA Administrator (IT).
  • Append-Only Audit Log (IEC 62443): Records the full history of write commands (who, when, value, command origin, and PLC response) that can never be edited or deleted.
